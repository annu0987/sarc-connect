# SARC Connect

A visually appealing multi-page React.js website created for the SARC Web Coordinator Assignment 2026.

## Features

- Responsive Navbar
- Home Page with Hero Section
- Events Page
- Stories Page
- Reusable Components
- Modern CSS Styling
- Hover Animations
- Multi-page Structure

## Technologies Used

- React.js
- CSS3
- Vite

## Folder Structure

src/
├── components/
├── pages/
├── styles/
├── App.jsx
├── main.jsx

## Description

This project was created to build an interactive and visually engaging frontend website for SARC. The website focuses on clean UI, responsive structure, and reusable React components.
